# Projeto de Análise de Vendas

Projeto avaliativo do curso de Análise de Dados com Python.

## Objetivo

Construir um pipeline de análise de dados utilizando PostgreSQL, SQL, Python e Pandas para tratar e analisar dados de vendas de uma rede de supermercados.

## Tecnologias

- PostgreSQL
- SQL
- Python
- Pandas
- Matplotlib
- Seaborn
- SQLAlchemy
- Git
- GitHub
